# AI时代大学生信息焦虑分析与个性化学习推荐系统

当前版本：`v1.0.11`

## 项目简介

这是一个面向大学生信息焦虑场景的毕业设计系统，围绕“测评 - 干预 - 复测 - 分析”形成闭环。系统不仅能完成 FOMO 焦虑测评，还会根据测评结果自动生成个性化干预计划，并支持后续复测对比，方便观察干预效果。

## 目录

- `backend/` Spring Boot 后端
- `frontend/` Vue3 前端
- `sql/schema.sql` 数据库脚本
- `docs/api.md` 接口说明

## 主要功能

- 用户注册、登录、JWT 鉴权、个人信息管理
- FOMO 焦虑测评与自动评分
- FOMO 测评补充画像项：睡眠时长、专注程度、通知干扰、目标清晰度
- 测评后自动生成干预计划
- 支持干预计划完成标记与复测前后对比
- 个性化学习推荐
- AI 聊天助手
- 数据可视化分析大屏
- AI 与科技新闻栏目
- 管理员后台总览、用户管理、测评管理、聊天管理、推荐管理
- SBTI 人格测试页内嵌展示
- 首页升级为项目总览首屏，支持快速跳转、最新状态展示和新闻摘要预览

## 项目亮点

- 形成“测评 - 干预 - 复测”的实际闭环，而不是单纯的打分展示
- 后台可看到全站用户、焦虑分布、AI 使用频率、推荐类型、干预完成率等统计数据
- 前端使用 Vue3 + Element Plus + ECharts，支持交互图表和响应式布局
- 后端使用 Spring Boot + MyBatis Plus + JWT，结构清晰，适合毕业设计演示
- AI 接口支持 OpenAI 兼容协议，未配置密钥时也可运行
- 新闻栏目支持 TechCrunch RSS 接入，未配置 `NEWS_FEED_URL` 时默认使用 TechCrunch 主 feed
- 新闻栏目支持本地 mock 回退，避免接口不可用时页面空白

## 启动顺序

1. 创建 MySQL 数据库并执行 `sql/schema.sql`
2. 修改 `backend/src/main/resources/application.yml`
3. 启动后端
4. 进入 `frontend/` 执行 `npm install`
5. 启动前端 `npm run dev`

## 默认管理员

- 用户名：`admin`
- 密码：`admin123`

## 说明

- AI 聊天接口支持 OpenAI 兼容接口
- 如果未配置 `AI_API_KEY`，聊天页会使用本地兜底回复，系统仍可完整运行
- 测评结果页会自动生成干预计划，后续可在结果页标记完成并查看复测变化
- FOMO 测试中的补充画像项不参与总分计算，主要用于生成更细化的干预建议和结果分析
